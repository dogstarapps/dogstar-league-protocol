# Dogstar League protocol development

- Keep source, comments and documentation in English.
- This repository contains public protocol code only. Keep application code, brand assets, private evidence, user data, credentials and private repository history outside it.
- Preserve all existing projects, changes, keys, databases and evidence. Follow the host disk-budget policy before installations and heavy builds; retain at least 20 GiB beyond conservative growth.
- Use Node from .nvmrc, exact dependencies and committed lockfiles. Never reuse a build from different sources to claim a pass.
- Keep demo balances and identities separate from live execution. Testnet operations are allowed for development. Real funds require reviewed deployments and explicit authorization.
- Preserve each player's individual positive profit and distinguish it from sponsor principal. Configurable shares are immutable round terms.
- Arbitrary rounds receive no MyLab, TERRY, POWER or HAW-AI authority.
- Public executors must not need a private Dogstar service or exclusive key. Claim and closure payouts use recorded recipients.
- Final buyout assigns enforceable residual rights against prefunded aggregate coverage; it cannot unfreeze external protocols.
- Maintain third-party notices and ABI provenance. Do not publish fetched third-party implementation binaries without established redistribution rights.
