# Security

This development protocol is not reviewed for real funds. Use Testnet for integration. Do not submit private keys, user data or sensitive audit evidence in public issues.

Contract authorization, code-hash pinning, token balance deltas, immutable round terms and prefunded exit obligations are independent controls. A frontend, catalog record or off-chain adapter status is not authorization. Registration requires signed consent; cash claims pay recorded beneficiaries. Operators cannot select replacement claim recipients.

Keep simulation identities and balances outside live calls. Never recover an ambiguous transaction by blindly rebuilding it. Pending signed envelopes belong to the operator's private journal and are excluded from source publication.

An external freeze or contract upgrade may stop a native exit. Closure commitments must account for this before admitting a position. Assigning residual rights does not unlock those assets. Do not describe a bounded reserve as guaranteeing unbounded profits.

Before changing public visibility, inspect the entire Git history, dependency/asset licenses and tracked files. This repository starts from an allowlisted source extraction without private application history or third-party implementation binaries.
